# GREEN ORGANIC FARMERS V3

Offline Android farm management app for pigs, feed, coffee, avocados, pregnancy, health and farm finance.

## Branding
- GREEN ORGANIC FARMERS logo on the startup screen
- GREEN ORGANIC FARMERS app icon
- Branded header logo

## Build
The project includes a GitHub Actions workflow at `.github/workflows/build-apk.yml` that builds a debug APK automatically.

After a successful workflow, download the APK from the workflow's **Artifacts** section.
